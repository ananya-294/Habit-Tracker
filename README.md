# HabitFlow – Daily Habit Tracker

A simple, offline desktop app for tracking daily habits

## Folder Structure

```
HabitFlow/
├── index.html      # The app's HTML structure (sidebar + 4 views)
├── style.css        # All styling: layout, colors, cards, dark mode
├── script.js         # All app logic: habits, rendering, Local Storage
├── main.js            # Electron's main process (creates the window)
├── package.json        # Project info and npm scripts
└── README.md             # This file
```
